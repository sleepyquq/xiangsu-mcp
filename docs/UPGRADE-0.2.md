## 已实现

- 版本检测和安装保护：读取实际 EXE 版本，插件安装到对应版本目录；只接受已审计 9.4.0，校验 agent-server.exe SHA256。提取器兼容新版非压缩格式，默认输出 `.local/catalog.candidate.json`，不直接覆盖正式清单。

- 实机修复：文字框和对齐改用组件 Enum，图片使用 Texture 字段和 GUID 绑定以支持子目录素材；脚本 targetId 支持 GUID 转唯一名称并拒绝重名。
- 截图明确落盘：指定 path 后解码图像并写入工程，返回尺寸/哈希；缺失图像或无法写入时报错。
- 坐标范围、运行时文件冲突保护、`.codex/` 限定文本写入、桥接代码与清单哈希检查、跨客户端会话锁、完成请求保留期清理。
- 9.4 脚本入口 setupGameScript，Texture/Material 字段绑定；兼容旧 userScript。
- 9.4 playLifecycle/playStep/playScreenshot/playHumanActions/playStateFields/playState。本地编排复用官方主机命令；状态查询要求真实运行日志，缺失不会返回伪造状态。
- 修正 getConsoleLogs 的 9.4 参数顺序为 startLine/count。

## 后续官方更新

官方更新并不必然破坏已有能力。当前安装器出于兼容性审查主动限制已核对的版本/哈希，因此新包先检查差异，再跑空项目回归；接口未变时主要是更新兼容基线。命令、参数或运行库锚点变化才需要相应代码调整。候选清单提取与回归脚本降低重复工作，但不能承诺内部接口永久兼容或自动接通所有新功能。
