### 发现并处理的音量差异

首轮真实试玩的旧音量断言失败。9.4.0 将原始值视为幅度，使用 20 倍常用对数和 [-70, -35] dB 窗口；9.4.1 改为能量，使用 10 倍常用对数和 [-16, -7] dB 窗口，两者曲线指数均为 0.7。旧输入 0.001 在新版映射为零，不能继续期待约 0.416。

MCP 仍传入底层原始值并保留官方运行库的转换，不强行恢复旧曲线。已修正适配说明，并按工程实际运行库 SHA256 选择回归样例：新版输入 0.1，断言约 0.753；低输入 0.0001 断言零；旧版仍保留原样例。未知运行库哈希会拒绝套用测试预期。

失败轮次已正常清理，保留证据，不计入成功验收。修正后完整轮次为 `6d75af4a-0345-4bdc-badf-c2dbe0269382`。测试副本的 `.codex/artifacts/blank94/` 保存 `scene-check-9.4.1.json`、`play-verified-<轮次>.json`、`verified-9.4.1.json`；`.codex/artifacts/playthrough/` 保存截图与视频。

### 复现

先在像塑中打开已确认可丢弃的空白测试副本，再依次运行：

```powershell
node scripts/blank-setup.mjs '测试工程绝对路径'
node scripts/blank-check.mjs '同一个测试工程绝对路径'
node scripts/blank-play.mjs '同一个测试工程绝对路径'
```

脚本不保存场景；测试素材和证据保留在副本。测试结束后可关闭窗口并选择不保存。本轮已通过 MCP 删除测试分组并核对空场景，未关闭用户窗口。
