# 官方 MCP 迁移与回退记录

2026-10-23 曾决定停止维护并迁移官方 MCP；2026-10-28 根据社区连接兼容性反馈恢复维护，当前方向见 [重启更新记录](RESTART.md)。本文保留之前的迁移证据和回退方法。

## 当时转向官方的原因

官方 MCP 已覆盖场景与资源编辑、脚本编译、预览交互和工程保存，并提供本项目未接入的图片/音频生成、AI 工作流及脚本动画/H5 流程。直接使用随编辑器更新的官方接口，可以避免继续维护一层依赖内部接口的桥接。

两者不能按工具数量比较：官方通过批量 DSL 聚合动作。本项目的运行状态读取与音频检测输入模拟尚未完成官方替代验证；恢复维护后将保留这些能力，并优先复用官方公开接口接入新增功能。

官方发布信息见 [像塑桌面版功能更新日志](https://bytedance.larkoffice.com/docx/RscSdNN59owmcaxXtk1cEGhun2c)，软件下载见 [像塑官网](https://effect.douyin.com/)。

## 使用官方 MCP

先启动像塑并打开目标工程，再通过编辑器提供的 MCP 安装流程配置客户端。

本机像塑 9.7.1 的官方接入参数为：

- 服务名：`xiangsu-mcp-manager`
- 传输：Streamable HTTP
- 地址：`http://127.0.0.1:17320/mcp`
- 官方全局 Skill：`xiangsu-effect-editor`，由编辑器安装包提供。

Codex 可通过 CLI 注册该地址：

```powershell
codex mcp add xiangsu-mcp-manager --url http://127.0.0.1:17320/mcp
```

地址以当前编辑器实际提供的值为准。客户端加载新配置后，调用 `health`、`list_instances`，再用 `get_project_context` 核对工程路径；后续每次操作明确传入 `instance_id`。

## 停用和回退

停用自制桥接时，先备份客户端配置及对应像塑版本的 `plugins.config.json`，仅移除 `CodexXiangsuMCP` 条目，保留其他插件和插件文件。保存工程并重新打开编辑器窗口后生效。

回退时使用与旧编辑器匹配的代码、插件和配置备份。恢复 `CodexXiangsuMCP` 条目后，在客户端注册原有 `xiangsu-editor` stdio 入口（`node` 加本仓库 `src/server.mjs` 的绝对路径）。先在测试副本核对会话、读回和预览，再操作正式工程。旧版本回退不代表其插件已兼容当前编辑器。

保留源码仓库原路径和既有路径连接；已安装的历史插件可能仍引用它。不要为了归档删除配置、插件目录、未提交候选或旧工程。
